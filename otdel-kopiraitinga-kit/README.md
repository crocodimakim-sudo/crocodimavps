# Отдел копирайтинга на ИИ (Claude и Codex): стартовый набор

Это не «один копирайтер», а маленькая редакция: исследователь, фактчекер, три автора, редактор-судья и чистильщик нейрослопа. Над ними руководитель отдела: перед каждым текстом он проводит с вами мини-интервью, потом раздаёт задачи и собирает результат.

**Структура, роли, модели, правила и порядок скилов уже настроены.** Вам нужно только: ответить на интервью при первом запуске и наполнить `reference-list/` своими авторами и текстами.

## Платформы: Claude и Codex из одного набора
Логика отдела описана один раз и не привязана к платформе:
- `AGENTS.md` — руководитель отдела. Его читает Codex, а `CLAUDE.md` для Claude Code просто ссылается на него. Дублей нет.
- `agents/*.md` — роли с уровнем модели (лёгкая / средняя / сильная), а не с её названием.
- `instrumenty/modeli.conf` — единственное место с названиями моделей: Claude haiku / sonnet / opus и OpenAI Terra / Sol / Astra.
- `sobrat-agentov.sh` собирает из этого `.claude/agents/*.md` для Claude Code и `.codex/agents/*.toml` для Codex.
- Скилы (`SKILL.md`) одинаковы для обеих платформ, отличается только папка: `.claude/skills/` или `.agents/skills/`.

## Как запустить (15 минут)

**Вариант А: Claude Code или Codex (рекомендуется: работают субагенты и скилы)**
1. Распаковать архив, открыть терминал в папке `otdel-kopiraitinga`.
2. `bash ustanovka.sh` (для обеих платформ), или `bash ustanovka.sh claude`, или `bash ustanovka.sh codex`. Скрипт соберёт агентов, поставит скилы и покажет команды для MCP.
3. Получить ключ Perplexity API и выполнить показанную команду `claude mcp add …` или `codex mcp add …`.
4. Для Codex: в `codex` набрать `/model` и сверить ID моделей с `instrumenty/modeli.conf`. Если отличаются, поправить файл и снова запустить `bash ustanovka.sh codex`.
5. Запустить `claude` или `codex` и написать «Привет». Руководитель отдела сам проведёт первое интервью, заполнит профиль и форматы площадок.
6. Положить в `reference-list/` авторов и тексты, которые он попросит (минимум 2 автора и 5 образцов).
7. Дальше просто: «Нужен пост в ТГ про …». Сначала короткое интервью, потом готовый файл в `export/`.

**Вариант Б: claude.ai или ChatGPT (проекты в чате)**
1. Создать проект, в инструкции вставить `MASTER_PROMPT.md`.
2. В файлы проекта загрузить `AGENTS.md`, папки `agents/`, `pravila-proekta/`, `formaty-kanalov/` и `reference-list/`.
3. Субагентов в чате нет: руководитель сам последовательно играет роли. Работает, но слабее: нет параллельных авторов и независимого редактора.

## Главная идея в трёх строках
1. **Своя библиотека**: референсы, форматы, стоп-слова. Без неё любой агент пишет усреднённо.
2. **Инструмент под задачу и уровень усилия под роль**: поиск на дешёвой модели и низком усилии (или в Perplexity), а думать и судить на сильной модели и высоком.
3. **Несколько авторов и редактор**: три черновика с разными углами, редактор ставит баллы по рубрике и выбирает. Потом обязательная чистка нейрослопа.
