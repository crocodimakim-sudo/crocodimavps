# Модели и уровень усилия (effort)

## Принцип
**Усилие покупает глубину мышления, а не качество поиска.** Поиск на высоком усилии почти бесполезен: модель дольше думает над теми же 10 результатами. Высокое усилие нужно там, где решение принимается: выбор угла, суд, сборка.

| Задача | Модель | Усилие | Комментарий |
|---|---|---|---|
| Поиск, сбор ссылок | haiku или Perplexity | low | Perplexity лучше для свежего: у него свой поисковый индекс |
| Транскрипция | не LLM: Whisper | — | LLM только для чистки транскрипта (haiku/low) |
| Фактчек | sonnet | medium | Сопоставить источники |
| Анализ ссылочной массы | sonnet + Ahrefs MCP | medium | Данные даёт Ahrefs, модель только интерпретирует |
| Черновик | sonnet | high | Основной рабочий режим |
| Стратегия, контент-план | opus | high | Мало токенов, много думать |
| Редактор-судья | opus | high | Не экономить |
| Антислоп | sonnet | medium | Работа по чек-листу |
| Формат, имена файлов | haiku | low | Механика |

## Как задаётся
- **Claude Code:** в шапке файла агента: `model: sonnet` и `effort: high`. В главной сессии: `/model`.
- **claude.ai:** модель выбирается в чате, режим размышлений (extended thinking) включать для роли редактора и стратегии, выключать для поиска.

## Перепроверить раз в квартал
Модели обновляются. Названия `haiku / sonnet / opus` — это семейства, Claude Code сам берёт актуальную версию.
