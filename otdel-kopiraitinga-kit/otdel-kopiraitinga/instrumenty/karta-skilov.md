# Карта скилов: что берём из каждого и что отключаем

Скилы с GitHub пишут разные люди, и они пересекаются. Если запустить всё целиком, получится каша: три скила по-разному правят один и тот же абзац, а «голос бренда» из чужого скила спорит с вашим `reference-list/`. Поэтому **у каждой задачи ровно один хозяин**, а из скилов берём только нужную часть.

## Кто хозяин каждой задачи
| Задача | Хозяин (единственный) | Кто НЕ трогает, хотя умеет |
|---|---|---|
| Интервью и бриф | `intervyu-brif` (свой) | grill-me не ставим: наш скил — его адаптация под тексты |
| Голос, тон, стиль | `reference-list/` + `formaty-kanalov/` | разделы про voice/tone в copywriting и copy-editing |
| Заголовки, крючки, CTA | `copywriting` | — |
| Структура продающего текста | `copywriting` | — |
| ИИ-структуры (тройки, «не просто X», однотипные абзацы) | `humanizer` | antislop-ru (у него проход 4 только для русских конструкций) |
| Русские слова: канцелярит, штампы, стоп-лист | `antislop-ru` | словарные списки humanizer (они английские) |
| Ясность, конкретика, доказательства | `copy-editing` | antislop-ru проход 6 только помечает `[нужен пример]` |
| Оценка «хорошо ли» | редактор + рубрика | оценочные шкалы внутри скилов не используем |
| Факты | фактчекер | никакой скил не добавляет факты |

## Что именно используем из каждого скила
| Скил | Используем | Не используем | Как это задаётся |
|---|---|---|---|
| **copywriting** (marketingskills) | формулы заголовков, крючки, структуры (PAS, AIDA и др.), CTA | советы по голосу бренда, SEO-раздел (есть свой формат), сбор контекста о продукте (есть интервью) | в задании автору: «из скила copywriting возьми только приёмы заголовков, структуры и CTA; голос — из reference-list» |
| **humanizer** | все структурные паттерны | английские словарные списки, переписывание тона | в агенте antislop: «humanizer: только структурные паттерны» |
| **antislop-ru** (свой) | все проходы 1–5, проход 6 только пометками | — | написан под эту схему |
| **copy-editing** (marketingskills) | проходы ясности, конкретики, доказательств, «так что?» | проход голоса и тона (это редактор), всё, что дублирует стоп-лист | в агенте antislop: «copy-editing: пропусти проходы voice/tone» |
| **transkribaciya** (свой) | целиком | — | — |

## Если ставите меньше скилов
Отдел работает и без внешних скилов, просто хуже на отдельных шагах:
- **Минимум:** `intervyu-brif`, `antislop-ru`, `transkribaciya` (все свои, лежат в архиве). Плюс Perplexity MCP.
- **Оптимум:** + `humanizer` + `copywriting` + `copy-editing`.
- **Не ставьте** другие «humanizer»/«anti-AI»/«brand-voice» скилы сверху: они дублируют этот набор, и Claude начнёт выбирать между ними случайно.

## Правило добавления нового скила
Перед установкой ответить: какую задачу из таблицы «хозяин» он забирает? Если хозяин уже есть — либо заменить старого, либо не ставить.
