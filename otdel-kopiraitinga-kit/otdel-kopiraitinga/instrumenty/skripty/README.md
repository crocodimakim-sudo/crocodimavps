# Локальные инструменты проверки текста

Скрипты работают с UTF-8 `.txt` и `.md`, без сети и внешних библиотек.
`.docx` не поддерживается: сначала сохраните текст как `.txt` или `.md`.
Правила: [стоп-слова и нейрослоп](../../pravila-proekta/03-stop-slova-neyroslop.md).

- `clean_text.py` удаляет невидимые символы, сохраняя русскую типографику.
  `--report` показывает изменения, `--check` проверяет без записи;
  `--nbsp-to-space` дополнительно заменяет неразрывные пробелы обычными.
- `detect_ai.py` выдаёт оценки и флаги по строкам; два файла дают «было/стало».
  `--json` включает машинный вывод, `--штампы` задаёт другой словарь.
- `test_tools.py` запускает проверки очистки и оценок без pytest.
- `штампы.json` хранит словарь фраз и слов; имя файла сохраняйте.

Пять оценок от 0 до 100 (больше — меньше признаков шаблонного текста):

| Оценка | Что проверяет |
| --- | --- |
| РИТМ | Разброс длины предложений и абзацев |
| КОНКРЕТИКА | Числа, единицы измерения, документы и имена |
| ШТАМПЫ | Плотность совпадений со словарём |
| СЛЕДЫ | Невидимые символы и частоту длинного тире |
| ГОЛОС | Повторяющиеся конструкции и оформление |

Итог = 60% среднего пяти оценок + 40% минимальной оценки.
ПРОШЁЛ: итог ≥70 и минимум ≥55. ПРОВЕРИТЬ: 50–69,
а также итог ≥70 при минимуме <55. ПЕРЕПИСАТЬ: итог <50.

Запускайте из корня проекта. macOS/Linux:

```sh
python3 instrumenty/skripty/clean_text.py текст.md -o чистый.md --report
python3 instrumenty/skripty/detect_ai.py чистый.md
python3 instrumenty/skripty/detect_ai.py чистый.md исправленный.md
```

Windows (PowerShell):

```powershell
python -X utf8 instrumenty/skripty/clean_text.py текст.md -o чистый.md --report
python -X utf8 instrumenty/skripty/detect_ai.py чистый.md
python -X utf8 instrumenty/skripty/detect_ai.py чистый.md исправленный.md
```

Порядок: очистить → замерить → ручная правка → сравнить «было/стало».
Сохраните очищенную версию для сравнения, правьте копию.
Два круга правок — норма. Проверки: `python3 instrumenty/skripty/test_tools.py`
или `python -X utf8 instrumenty/skripty/test_tools.py` в Windows.

В `штампы.json` записи в массивах `фразы` и `слова` содержат:
`найти` — регулярное выражение Python без учёта регистра;
`семья` — группа оборотов; `совет` — подсказка для ручной правки.

Это эвристики, а не детектор авторства. Флаг означает «посмотри»:
уместную фразу можно оставить. Балл не доказывает происхождение текста
и не гарантирует результат стороннего детектора.

Источник идеи: [ig-human](https://github.com/Jakeschincariol/instagram-agent-skill),
лицензия MIT. Код написан заново под русский язык.
