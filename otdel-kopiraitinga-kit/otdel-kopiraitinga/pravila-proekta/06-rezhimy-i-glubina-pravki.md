# Режимы и глубина правки

Режим определяется **до интервью**: от него зависит, сколько шагов пайплайна нужно.

## Слова владельца → режим → глубина
| Слова владельца | Режим | Глубина |
|---|---|---|
| «исправь ошибки», «вычитай» | `edit` | **L0**: опечатки, орфография, пунктуация |
| «поправь», «причеши» | `edit` | **L1**: локальный синтаксис; факты, порядок и тон не меняются |
| «перестрой» | `edit` | **L2**: новый порядок без нового смысла |
| «перепиши», «под другую аудиторию» | `rewrite` | **L3**: новая композиция, все факты сохраняются |
| «напиши», бриф | `create` | **L4**: текст с нуля, факты не придумываются |
| «сделай из статьи пост» | `adapt` | новый жанр; переносятся только доказанные утверждения |
| «оцени», «проверь текст» | `audit` | таблица «проблема → последствие → исправление → приоритет»; текст не переписывается |
| «дай варианты» | `variants` | только по просьбе; варианты отличаются ракурсом, а не синонимами |

**«Поправь» без уточнения = L1, а не переписывание.**

## Режим → какие шаги пайплайна идут
| Режим | Интервью | Кто пишет | Дальше |
|---|---|---|---|
| L0–L2 | нет (максимум 1 вопрос, если неясно) | один автор, средняя модель, усилие medium | замер скриптами (шаг 5) и выпуск (шаг 7). Редактор-судья и три автора не нужны |
| L3 | короткое: 2 вопроса | 1–3 автора | суд, чистка, выпуск |
| `create` L4, `adapt` | полное | три автора | полный пайплайн 0–8 |
| `audit` | нет | только редактор по рубрике | таблица проблем, без переписывания |

Правки L0–L2 не меняют неприкосновенные реквизиты (см. `01-obshchie-pravila.md`, реестр фактов).

## Что выдавать
- «Поправь» и «напиши»: только готовый текст, без предисловий.
- Список правок: только по просьбе.
- Ограничение длины от владельца важнее нормы площадки. Считать по символам с пробелами.
- Сокращать за счёт фактов и обязательных условий нельзя.
