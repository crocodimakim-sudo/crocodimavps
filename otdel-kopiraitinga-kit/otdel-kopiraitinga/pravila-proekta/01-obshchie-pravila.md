# Общие правила проекта

1. **Иерархия источников истины:** бриф > `formaty-kanalov/` > `reference-list/` > эти правила > общие знания модели.
2. **Нет источника — нет факта.** Любая цифра, дата, цитата, исследование проходят через фактчекера и получают класс из реестра фактов (ниже).
3. **Одна площадка = один текст.** Адаптация под другую площадку = новый прогон авторов.
4. **Папки:** входящее только в `import/`, финал только в `export/`, всё остальное в `archive/`. Ничего не удалять, только переносить в архив.
5. **Библиотека меняется только по слову владельца.** Агенты предлагают изменения в отчёте; добавить текст в `reference-list/primery/` главред может только после «да» владельца.
6. **Усилие по роли:** поиск дешёвый, суждение дорогое (см. `../instrumenty/modeli-i-usilie.md`).
7. **Язык:** русский, «ты» или «вы» по `formaty-kanalov/`. Ё пишем [да/нет — выбрать].
8. **Запрещено:** выдумывать отзывы, кейсы, цифры, цитаты; обещать результат («гарантированно похудеете»); медицинские и юридические советы без оговорки; чужой текст без кавычек и ссылки.
9. **Учимся:** после каждой задачи, если антислоп нашёл новое частое слово-паразит, главред предлагает добавить его в стоп-лист.

## Реестр фактов
Каждое существенное утверждение относится к одному из пяти классов.

| Класс | Что значит | Что делать в тексте |
|---|---|---|
| `GIVEN` | дал владелец или его материалы в `import/` | использовать |
| `VERIFIED` | проверено по первоисточнику, указаны источник и дата | использовать |
| `INFERRED` | вывод из данных | писать условно («похоже», «скорее всего») |
| `UNKNOWN` | данных нет | поставить метку `{{цифра}}` или `{{пример}}`, либо задать владельцу один вопрос. **В финал с меткой не выпускать** |
| `EXAMPLE` | придуманный пример | всегда помечать как пример |

Соответствие старым значкам: GIVEN и VERIFIED = ✅, INFERRED = ⚠️ (только с оговоркой), UNKNOWN = ❌.

**Неприкосновенные реквизиты при правках L0–L2:** имена, должности, номера и даты документов, суммы, сроки, единицы, ссылки, отрицания, модальность («обязаны» не смягчать до «будем рады»). До правки выписать, после правки сверить буквально. Расхождение в одном символе = стоп.

**Источник противоречит владельцу.** Молча не исправлять: оставить формулировку владельца и назвать расхождение отдельной строкой в отчёте.
