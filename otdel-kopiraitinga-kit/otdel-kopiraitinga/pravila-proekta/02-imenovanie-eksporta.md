# Именование файлов экспорта

## Формат
```
NNNN_ГГГГ-ММ-ДД_площадка_тема-латиницей_vN.расширение
```
| Часть | Правило | Пример |
|---|---|---|
| `NNNN` | Сквозной номер задачи, 4 цифры, не сбрасывается | `0012` |
| `ГГГГ-ММ-ДД` | Дата выпуска (так файлы сортируются по времени) | `2026-11-09` |
| `площадка` | `tg`, `lj`, `ig`, `blog`, `mail`, `vk`, `dzen` | `tg` |
| `тема` | 2–5 слов транслитом через дефис | `kak-vybrat-trenera` |
| `vN` | Версия. Новая правка того же текста = v2, старая уходит в `archive/` | `v1` |

Пример: `0012_2026-11-09_tg_kak-vybrat-trenera_v1.md`

## Подпись
Каждый файл в `export/` начинается с шапки `shablony/shapka-eksporta.md`: номер, дата, площадка, бриф, победивший автор, балл редактора, проверенные факты.

## Сжатие
- Один текст: `.md` без сжатия.
- Пакет (контент-план на неделю, текст + картинки, несколько площадок): `NNNN_ГГГГ-ММ-ДД_paket_тема.zip` (`zip -9`).
- Раз в месяц всё из `archive/` старше 30 дней: `archive/ГГГГ-ММ_arhiv.zip`.
