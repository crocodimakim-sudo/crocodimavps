# Жанр, тон, голос: три независимые оси

Каждая ось выбирается отдельно и записывается в бриф. Жанр задаёт композицию. Форма конкретной площадки (длина, разметка) лежит в `formaty-kanalov/`.

## Жанр
| Жанр | Композиция | Чего не делать на автопилоте |
|---|---|---|
| Пост в Telegram | конкретный заход → одна мысль → пример → вывод | эмодзи ради эмодзи, фальшивая интрига |
| Колонка в ЖЖ | личный случай → позиция → аргументы → итог | обучающий тон, список советов |
| Подпись в Instagram | зацепка в первой строке → короткая история → один призыв | простыня текста, пачка хештегов |
| Статья для блога / SEO | вопрос → прямой ответ → объяснение → пример или данные → итог | вода, набивка ключами, пустые подзаголовки |
| Рассылка | один повод → польза → одно действие | несколько призывов сразу |
| Деловой мессенджер | причина → главное → один вопрос | длинное вступление, давление |
| Лендинг | для кого → проблема → предложение → как работает → доказательства → условия → призыв | придуманная конверсия |
| Кейс | задача → действия → проверяемый результат → ограничения | сочинённые метрики |
| Инструкция | условия до начала → шаги по порядку → проверка результата → ошибки | «просто сделайте», реклама |
| Пресс-релиз | новость → кто, что, когда → контекст → цитата только реальная → контакты | реклама вместо новости |

**Антитест.** Просили инструкцию, а получилась реклама: переписать. Письмо, похожее на пресс-релиз, сократить.

## Тон
Тоны: нейтральный, тёплый, дружеский, экспертный, убеждающий, премиальный, игривый, бережный, критический.

| Тон | Типичная подмена |
|---|---|
| дружеский | фамильярность («друзья, погнали») |
| экспертный | длинные предложения и термины |
| премиальный | эпитеты без доказательств |
| убеждающий | давление и обещания результата |

Тон не переносится между жанрами: шутка из поста не попадает в официальный текст.

## Голос
| | Личный | Бренд | Нейтральный |
|---|---|---|---|
| Лицо | «я» | «мы» = компания; «я» нельзя | без лица |
| Опыт | только реальный | опыт компании с датами и документами | только документы и данные |
| Ирония | можно | дозированно, не над клиентом | нет |
| Где | личный блог, пост от своего имени | сайт, КП, письма от компании | инструкции, справки, отчёты |

## Правила
1. Голос выбирается **до** текста и пишется в бриф. Внутри одного текста не меняется.
2. Если в тексте бренда нужен опыт человека: короткая реальная цитата с именем и ролью.
3. «Давайте посмотрим» не используем ни в одном голосе.
