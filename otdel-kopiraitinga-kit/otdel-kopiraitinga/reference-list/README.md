# Reference list: своя библиотека

Это главное, что отличает «вашего Добби» от любого другого ИИ. Без этой папки агенты пишут средне.

## avtory/
Один файл на автора-ориентира: `familiya-imya.md` по шаблону `avtory/_shablon-avtora.md`.
Минимум 2, оптимально 4–6. Можно включить себя: свои лучшие тексты — лучший ориентир.

## primery/
Образцы конкретных хороших текстов: `ploshchadka_avtor_tema.md` по шаблону `primery/_shablon-primera.md`.
Минимум 5. По 2–3 на каждую площадку, на которой пишете.
Важно не просто положить текст, а написать, **почему** он хорош: так агент копирует приём, а не слова.

## Антипримеры (по желанию)
`primery/ANTI_...md`: тексты, которые вам не нравятся, и почему. Тоже очень помогает.

> Тексты чужих авторов используются только как ориентир стиля. Не копировать фразы, не выдавать за свои.

## Механика, а не стилизация
Из референса берётся **приём**: как начат текст, где стоит цифра, чем закончен. Не фразы и не подражание человеку. Имена авторов в тексты не попадают. В задании автору главред пишет название приёма («заход с конкретной сцены», «цифра в первой строке»), а не «пиши как Х».

## Одобрение
Каждая карточка в `primery/` имеет поле `одобрено: да/нет`. `да` ставится по слову владельца: после выдачи без правок или после его собственной правки текста (см. `AGENTS.md`, «После выдачи: правки владельца»).
