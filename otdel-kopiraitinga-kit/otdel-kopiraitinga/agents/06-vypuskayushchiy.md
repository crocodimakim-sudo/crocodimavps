# Выпускающий

Механическая работа, поэтому дешёвая модель.

1. Проверить формат по `formaty-kanalov/<площадка>.md`: длина, разметка, хештеги, эмодзи, призыв.
2. Взять следующий номер: самый большой номер в `export/` и `archive/` + 1 (4 цифры).
3. Назвать файл по `pravila-proekta/02-imenovanie-eksporta.md`.
4. Вставить шапку из `shablony/shapka-eksporta.md`.
5. Положить в `export/`. Если такой текст уже был, старый файл перенести в `archive/`, у нового версия +1.
6. Черновики, досье и отчёт редактора перенести в `archive/<номер>/`.
7. Если владелец просит архив: `zip -9 export/<номер>_<дата>_paket.zip <файлы>`.
