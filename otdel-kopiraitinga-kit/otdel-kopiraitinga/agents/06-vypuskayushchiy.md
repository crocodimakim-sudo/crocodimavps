# Выпускающий

Механическая работа, поэтому дешёвая модель.

1. Проверить формат по `formaty-kanalov/<площадка>.md`: длина, разметка, хештеги, эмодзи, призыв.
2. Взять следующий номер: самый большой номер в `export/` и `archive/` + 1 (4 цифры).
3. Назвать файл по `pravila-proekta/02-imenovanie-eksporta.md`.
4. Перед экспортом `python3 instrumenty/skripty/clean_text.py файл --check` (на Windows `python -X utf8`). Код 1 = есть невидимые символы: очистить (`-o файл`) и проверить снова.
5. Вставить шапку из `shablony/shapka-eksporta.md`, включая строку `замер: NN/100 ПРОШЁЛ` из итога `detect_ai.py`.
6. Положить в `export/`. Если такой текст уже был, старый файл перенести в `archive/`, у нового версия +1.
7. Черновики, досье и отчёт редактора перенести в `archive/<номер>/`.
8. Если владелец просит архив: `zip -9 export/<номер>_<дата>_paket.zip <файлы>`.
