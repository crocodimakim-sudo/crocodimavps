# import/ — всё входящее
- `brify/` — брифы (`NNNN_ГГГГ-ММ-ДД_brif.md`)
- `transkripty/` — расшифровки видео, Reels, подкастов, голосовых (`NNNN_istochnik_tema.md`)
- `materialy/` — ваши заметки, скрины, голосовые, черновики мыслей

Сюда можно кидать что угодно в любом виде. Агенты отсюда только читают (кроме транскриптов и брифов).
