# Статья для блога / SEO

- **Длина:** по брифу (обычно 6000–15000 знаков).
- **Ключевые запросы:** из брифа. Основной в H1, первом абзаце, 1–2 H2. Без переспама (проверка: turgenev.ashmanov.com).
- **Структура:** H1 → лид (ответ на запрос в первых 2–3 предложениях) → H2/H3 → FAQ (3–5 вопросов) → вывод с действием.
- **Ссылки:** 2–5 внешних на авторитетные источники (проверены фактчекером), 2–4 внутренних.
- **Мета:** Title до 60 знаков, Description до 160 знаков. Отдать отдельным блоком.
- **Голос:** экспертный, но человеческий. Опыт владельца и примеры важнее пересказа чужих статей (это и для поисковиков сейчас важно).
