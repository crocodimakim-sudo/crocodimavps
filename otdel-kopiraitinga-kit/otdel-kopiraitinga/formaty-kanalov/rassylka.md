# Email-рассылка

- **Тема письма:** до 50 знаков, 3 варианта на выбор. Прехедер до 90 знаков.
- **Длина:** 800–2500 знаков.
- **Обращение:** по имени, если есть переменная `{{name}}`.
- **Одна мысль и одно действие** на письмо. Одна кнопка.
- **P.S.** работает, использовать для второго по важности сообщения.
