# Управление сервером OpenClaw + VPN (GitOps)

Этот репозиторий — **источник правды и «память»** о конфигурации сервера. Идея:
изменения описываются здесь, а **OpenClaw-агент на сервере** делает `git pull` и
применяет их идемпотентными скриптами. Ничего лишнего не перезапускается,
история всех изменений видна в git.

> **Почему не по SSH напрямую из сессии Claude?** Облачное окружение, где запущен
> веб-агент, режет весь исходящий трафик кроме белого списка (порт 22 закрыт даже
> к github.com). Поэтому исполнитель — агент **на самом сервере**, а не эта сессия.

## Топология (два сервера)

| # | Сервер | Роль | Что здесь настраивается |
|---|--------|------|-------------------------|
| 1 | Alibaba VPS | OpenClaw + sing-box (**клиент** VPN) | правила маршрутизации, перезапуск сервисов |
| 2 | AEZA `62.60.236.230` | xray VLESS+REALITY (**сервер** VPN) | добавление/удаление друзей, уникальные ссылки |

## Структура

```
state/                    # декларативное состояние = память
  servers.yaml            # инвентарь серверов и пути к конфигам
  friends.yaml            # реестр друзей (БЕЗ секретов: имя, дата, статус)
  routing.yaml            # правила: какие домены DIRECT, какие через VPN
scripts/                  # идемпотентные исполняемые скрипты
  config.sh               # несекретные параметры (пути, endpoint, публичный ключ)
  lib.sh                  # общие функции (бэкап, валидация, лог)
  vpn-friend-add.sh       # + друг -> уникальный UUID+shortId -> уникальная ссылка
  vpn-friend-remove.sh    # - друг (отзыв доступа, остальных не трогает)
  vpn-friend-list.sh      # список друзей
  restart-service.sh      # перезапуск ТОЛЬКО одного сервиса
  apply-routing.sh        # применить routing.yaml к sing-box
.secrets/                 # gitignore: сюда пишутся UUID друзей (это пароли доступа)
```

## Быстрый старт (на сервере AEZA)

```bash
git clone <repo> && cd crocodimavps
# добавить друга Vasya — печатает уникальную VLESS-ссылку:
sudo scripts/vpn-friend-add.sh vasya
# список:
scripts/vpn-friend-list.sh
# отозвать доступ:
sudo scripts/vpn-friend-remove.sh vasya
```

Каждый друг получает **свой UUID и свой shortId** → ссылки гарантированно разные,
и любого можно отключить отдельно, не ломая доступ остальным.

## Правило секретов

UUID в VLESS — это фактически пароль доступа к VPN. Поэтому реестр UUID пишется в
`.secrets/` (в `.gitignore`), а в git попадают только имена и статусы друзей.
Живые ключи/пароли в репозиторий не коммитятся (см. `CLAUDE.md`).
