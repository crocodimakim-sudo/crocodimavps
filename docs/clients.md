# Настройка клиентов (Shadowrocket / Hiddify)

После того как на сервере создан inbound **VLESS + Reality**, панель 3x-ui
даёт ссылку вида `vless://...` и QR-код. Они одинаково импортируются в оба
клиента. Здесь — как импортировать и как починить обрывы/IPv6/403 на ПК.

---

## 1. Где взять ссылку

Панель 3x-ui → твой inbound → значок **«Подключиться» / QR**. Скопируй ссылку
`vless://...?type=tcp&security=reality&...#kim` или покажи QR.

> Важно: в адресе сервера должен стоять **IPv4** `62.60.236.230`,
> а НЕ доменное имя, которое может резолвиться в IPv6.

---

## 2. Shadowrocket (iPhone) — у тебя уже работает

1. Скопируй ссылку `vless://...`.
2. Открой Shadowrocket → он сам предложит добавить из буфера, либо `+` →
   вставь ссылку.
3. Подключись. Готово.

Если когда-нибудь начнёт рваться — в настройках профиля проверь, что выключен
**Mux**, и в общих настройках стоит «**Prefer IPv4**».

---

## 3. Hiddify (ПК) — здесь и были обрывы + 403

Твоя проблема: Hiddify уходил в **IPv6**, трафик к Anthropic ловил **403**, и
соединение «отваливалось». Серверную часть лечит `03-ipv4-outbound.sh`. На
**клиенте** нужно дополнительно запретить IPv6 — иначе Hiddify снова уйдёт в v6.

### Импорт конфига
- **Профиль → Добавить → Из буфера обмена** (вставь `vless://...`), либо
  **Добавить из QR**.

### Обязательные настройки (Настройки конфигурации / Config Options)
Открой **⚙️ Настройки → «Настройки конфигурации»** и выставь:

| Параметр | Значение | Зачем |
|---|---|---|
| **IPv6** / «Поддержка IPv6» | **Выключить (Disable)** | Чтобы клиент не уходил в IPv6 |
| **Remote DNS domain strategy** | **`ipv4_only`** (или `prefer_ipv4`) | DNS отдаёт только IPv4 → нет 403 от Anthropic |
| **Direct DNS domain strategy** | **`ipv4_only`** | то же для прямых запросов |
| **Mux (мультиплексирование)** | **Выключить** | С Reality mux часто даёт обрывы |
| **TLS Fragment / TLS Tricks** | **Выключить** | Лишнее для Reality, может ронять хендшейк |
| **Режим (Connection/TUN)** | **TUN / VPN** | Стабильнее системного прокси |
| **Strict Route** | Включить | Меньше утечек мимо туннеля |

После изменения настроек: **переподключись** (Disconnect → Connect).

### Проверка
- В Hiddify внизу/в логах посмотри, по какому адресу идёт коннект к серверу —
  должен быть **62.60.236.230 (IPv4)**, не `2a0...` (это был бы IPv6).
- Открой `https://api.anthropic.com` / Claude — **403 должен пропасть**.

---

## 4. Если всё равно рвётся

1. На сервере прогони `sudo bash scripts/diagnose.sh` — проверь, что:
   - время синхронизировано (Reality рвётся при расхождении часов);
   - `freedom outbound` = **ForceIPv4**;
   - `api.anthropic.com` по IPv4 даёт **НЕ 403**.
2. В Hiddify убедись, что **IPv6 выключен** и **Mux выключен**.
3. Попробуй сменить порт inbound на **443** (меньше режется провайдером).
4. См. `docs/troubleshooting.md`.
